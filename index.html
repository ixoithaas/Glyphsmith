Tips for a clean trace

  • Keep characters separated — no touching strokes between neighbours.
  • Even spacing in rows makes Auto-detect and Grid slice effortless.
  • Photograph straight-on, avoid shadows across the page.
  • Blotchy photo? Raise the threshold / clean-up sliders in Step 2.

Your font will include .notdef + space automatically; every mapped character becomes a glyph. If you tweak boxes or settings after building, downloading rebuilds first — you always get the latest.

🪟 Windows

Right-click the .ttf → Install, or drop it into C:\Windows\Fonts.

🍎 macOS

Double-click the .ttf and choose Install Font in Font Book.

🐧 Linux

Copy it to ~/.local/share/fonts and run fc-cache -f.

How it works under the hood

Each box is cropped, thresholded to a 1-bit bitmap, and traced with a marching-squares contour follower. Contours are simplified (Douglas–Peucker), optionally smoothed into quadratic Béziers, holes are counter-wound, then scaled into a 1000-unit em with per-class heights. opentype.js builds the Font object, glyphs and metrics; because that release only writes CFF-flavoured OpenType, Glyphsmith then serialises the same font object into genuine TrueType glyf/loca/cmap/head/name tables — the exact bytes your OS expects from any font foundry.
